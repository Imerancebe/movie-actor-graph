## T3 图挖掘（③数据管理与挖掘层·自主算法）

- [x] **T3.1** `pipeline/05_graph_mining.py`：Spark 读取图数据 → 自主实现**加权 PageRank**（RDD 迭代）→ 回写 Neo4j — FR-M3；判据：收敛日志 + 排名头部为高知名度演员，`a.pagerank` 属性可查

- [x] **T3.2** 同脚本：自主实现**标签传播 LPA 社区发现** → 连续社区编号回写 — FR-M4；判据：`a.community` 属性存在，社区数 5\~200 量级合理

- [x] **T3.3** 同脚本：度中心性 / 多产榜 / 热门电影榜计算回写 — FR-M5；判据：三类榜单 CSV 产出

- [x] **T3.4** 同脚本：**Adamic-Adar + Jaccard 合作预测**，Top-N 预测结果导出 — FR-M6；判据：预测表含共同合作者证据字段

- [x] **T3.5** `pipeline/06_sna_analysis.py`：Spark 三角计数 + 全局/局部聚类系数、多源位图 BFS 采样平均路径与直径（FR-M7 小世界特性）；驱动端 K-core 剥壳（FR-M9） — 判据：`sna_summary.json` 产出，聚类系数 ≫ 同规模随机图（实测 0.781 vs 基线 0.00045，约 1750 倍）、平均路径与随机图基线同数量级（实测 11.09 vs 4.36，远小于网络规模 22K；判据修订：原「≪6」为估算乐观值，实测巨片呈"国家影圈链"结构致路径偏长），`a.kshell` 属性可查

- [x] **T3.6** 同脚本：Brandes 介数中心性（度数 Top-1000 核心子图精确计算，FR-M8）+ 度分布幂律拟合（无标度验证） — 判据：`a.betweenness` 榜单含归一化分值（回写 678 人），log-log 度分布斜率产出（实测 -2.254）

- [x] **T3.7** 同脚本：合作网络年代演化（FR-M10） — 判据：`evolution.csv` 累计合作边数收敛至 CO_ACTOR 总数（实测 110,822 = 110,822 ✓）
- [x] **T3.8** `pipeline/07_link_prediction_eval.py`：随机隐藏 20% 边，CN/Jaccard/AA(标准)/AA(√变体)/PA 五算法对比实验，AUC（同分修正秩和法）+ Precision@100/500（FR-M11） — 判据：`prediction_eval.json` 产出，五算法 AUC 全部显著 > 0.5 随机基线，邻域类算法 > PA
- [x] **T3.9** `pipeline/08_embedding.py`：度数 Top-5000 子图加权随机游走 + PPMI 共现矩阵 + 截断 SVD 得 64 维嵌入（FR-M12） — 判据：`actor_embeddings.csv` 等四个产出齐全；嵌入法链接预测 AUC 与 AA 可比（差距 < 0.1），PCA 散点呈现社区聚集
- [x] **T3.10** `pipeline/09_genre_mining.py`：类型共现网络 + 演员类型画像（Shannon 多样性）+ 类型年代演化（FR-M13，回写 Neo4j） — 判据：三个 CSV 产出；共现边计数 = ΣC(类型数,2) 精确一致；多样性榜可查
